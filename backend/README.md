# Portfolio Backend

A secure and scalable backend for a Full Stack Portfolio Website built with Node.js, Express.js, MySQL, and Sequelize ORM. It provides RESTful APIs for portfolio management, authentication, admin dashboard, blogs, projects, contact messages, and more.

## Tech Stack

- Node.js
- Express.js
- MySQL
- Sequelize ORM
- JWT Authentication
- Bcrypt
- Nodemailer
- Multer
- Helmet
- Express Rate Limit
- CORS

## Features

- Secure JWT Authentication
- OTP Email Verification
- Admin Dashboard APIs
- CRUD Operations
- Project Management
- Blog Management
- Skills Management
- Education Management
- Certificate Management
- Achievement Management
- Testimonial Management
- Contact Form API
- Notification System
- SEO Management
- File Upload Support
- Email Integration
- Security Middleware
- RESTful API Architecture

## Installation

```bash
npm install
```

Create a `.env` file and configure your environment variables.

Start the development server:

```bash
npm run dev
```
